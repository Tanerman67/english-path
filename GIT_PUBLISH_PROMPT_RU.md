# Промпт для ChatGPT Work — публикация English Path на GitHub

Я прикрепил ZIP-архив `English_Path_Work_Ready.zip` с полным исходным кодом отдельного веб-приложения English Path, включая 7 уроков и настройки GitHub Pages.

**Задача:** распакуй архив, изучи `WORK_HANDOFF.md` и `README.md`, проверь исходники и тесты, затем опубликуй приложение в новом репозитории моего подключённого GitHub под названием `english-path` и настрой GitHub Pages.

Важные требования:

- Это отдельный проект, не связанный с My Rhythm. Не затрагивай существующие репозитории и файлы.
- Не переписывай приложение с нуля, не заменяй его React-шаблоном и не меняй ID уроков. Сначала опубликуй уже подготовленный работающий MVP.
- Запусти `npm test`, затем проверь приложение в браузере через локальный сервер. Особое внимание удели сохранению прогресса после перезагрузки, упражнениям, Review, Library и экспорту/импорту JSON.
- Загружай в GitHub **содержимое архива**, а не ZIP как один файл. Сохрани `.github/workflows/pages.yml`.
- Если репозиторий уже существует или нужны права на создание/публичную видимость, остановись и запроси моё решение. Не перезаписывай существующий репозиторий.
- В GitHub Pages выбери публикацию через GitHub Actions. Дождись успешного workflow и открой действующую ссылку сайта для проверки.
- Не добавляй в публичный репозиторий личные данные, резервные копии пользователей или секреты.
- После завершения пришли ссылку на GitHub-репозиторий, ссылку на сайт, статус проверки, commit SHA и список ограничений первой версии.

Если найдёшь ошибки, исправляй минимально и перепроверяй тестами. Не утверждай, что сайт опубликован, пока это не подтверждено GitHub Actions и проверкой URL.
